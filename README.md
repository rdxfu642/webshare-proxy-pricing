Every proxy provider has them. Webshare's are mild compared to most, but worth knowing.

**Bandwidth overage:** If you blow past your monthly allowance, additional bandwidth is billed per GB at a rate that varies by plan tier. Set bandwidth alerts in the dashboard before you start a heavy job.

**IP refresh frequency:** On shared plans, IPs rotate monthly by default. If you want fresher IPs, manual refresh costs nothing on most tiers — but some users miss this and assume IPs are dynamic by default.

**Geo-targeting:** Country-level targeting is included free. City-level targeting on residential plans can affect pricing slightly.

**Concurrent threads:** Each plan has a thread limit. Exceed it and connections start failing. The Starter's 100 threads is enough for most scrapers, but heavy concurrent operations need a bigger plan.

None of these are gotchas in the predatory sense. They're just configuration details that, ignored, lead to "wait, why's my bill higher?" moments.
